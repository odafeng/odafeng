### 🔬 What I Build

**🎯 Before Surgery — predict difficulty before the first incision**
Automated CT pelvimetry and body composition analysis to forecast how hard a rectal cancer operation will be. Published as [`ctpelvimetry`](https://pypi.org/project/ctpelvimetry/) on PyPI; FREDRIC framework for surgical difficulty scoring.
→ [`Auto_ISD_Pelvimetry`](https://github.com/odafeng/Auto_ISD_Pelvimetry) · [`ctpelvimetry`](https://github.com/odafeng/ctpelvimetry)

**🎥 During Surgery — learn from every operation**  
Video-based learning curve analysis using RA-CUSUM; ML risk modeling for robotic colorectal surgery safety; NMF-based surgical difficulty decomposition.
→ [`RiSSA_ML_Learning_Curve`](https://github.com/odafeng/RiSSA_ML_Learning_Curve)

**📱 After Surgery — keep patients in the loop**  
Digital symptom monitoring apps and AI-assisted patient education for postoperative care.
→ [`Hemorrhoids_PostOp`](https://github.com/odafeng/Hemorrhoids_PostOp)
